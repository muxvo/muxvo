# Muxvo 操作指南

> 本文是 Muxvo 内置的使用指南。点击右上角「?」帮助按钮时，Muxvo 会新建一个终端并让 Claude
> 读取本文，之后你可以直接在那个终端里用自然语言提问（例如「怎么把终端收起来？」「主题在哪改？」），
> Claude 会基于本文回答。

## Muxvo 是什么

Muxvo 是一个 macOS 终端工作台：一个窗口里同时开多个终端（网格平铺），配合文件面板、聊天历史、
AI 任务编排等能力，专为高频使用 Claude Code / Codex 等 AI CLI 的用户设计。终端由原生 Metal 直渲，
大量输出下依然流畅。

## 界面总览

- **顶部菜单栏**：左侧是页签（终端 / Skills / MCP / Hooks / Plugins / 历史聊天），右侧是
  登录、帮助（?）、设置（齿轮）按钮。
- **中间主区**：终端网格（默认平铺 Tiling）。
- 每个终端卡片（tile）有标题栏：目录名、Git 分支/worktree 标记、自定义名称、以及悬停出现的
  按钮（文件、worktree、聚焦、收起、关闭）。

## 终端基本操作

- **新建终端**：右下角 `+` 浮动按钮，或 `⌘T` / `⌘N`，或菜单「文件 → 新建终端」。
- **关闭终端**：悬停终端标题栏点 `×`。运行中的会话会弹确认框（防误关）；已结束的直接关闭。
- **重命名**：单击终端标题栏的名称位置，输入后点别处提交；清空则回落默认目录名。
- **选中/聚焦**：单击终端即选中；点终端标题栏的聚焦按钮（⤢）把它最大化为单终端视图，再点一次
  或点「返回平铺」回到网格。
- **双击聚焦**：设置里可开启「双击聚焦」，开启后双击终端直接进聚焦视图。
- **调整布局**：拖拽终端可交换位置；拖动网格分隔条调整行列比例。
- **字号缩放**：`⌘+` / `⌘-` / `⌘0`（终端网格下缩放终端字号；全页面板下缩放面板）。
- **行首/行尾**：`⌘←` / `⌘→`。
- **搜索**：`⌘F` 打开终端内搜索条，回车下一个，`Esc` 关闭。
- **粘贴**：`⌘V`（多行粘贴有确认保护）。

## 终端收起与列表模式

- **收起**：点终端标题栏的收起按钮（▁），终端缩进左侧边栏细条，进程继续运行。
  - 细条上每个圆点 = 一个收起的终端；**点圆点直接恢复**该终端回网格。
  - 细条顶部的 `»` 按钮展开卡片列表，可看到每个收起终端的名字和最后一行输出；
    悬停卡片右侧出现 `×` 可直接关闭该终端。
- **列表模式**：`⌘⇧L`（或菜单「显示 → 列表模式」）把网格切成「左列表 + 右详情」的单终端浏览
  视图，点列表行切换详情；再按一次切回平铺。

## 多窗口

- `⌥⌘N` 新建 Muxvo 窗口。每个窗口独立一套终端网格（每窗上限 20 个终端，全局 40）。
- 窗口布局和打开的终端会持久化，重启后恢复。

## 文件面板与 worktree

- **文件面板**：点终端标题栏的「文件」按钮（或 `⌘E`）打开当前目录的文件树；点 Markdown/代码
  文件进入 tab 式文件视图（支持编辑和 `⌘S` 保存）；设置里的「眼睛」开关控制是否显示隐藏文件。
- **worktree**：Git 仓库的终端标题栏会出现 worktree 按钮，点开浮层可创建/删除 git worktree，
  并直接在对应 worktree 目录开新终端——多任务并行改代码互不干扰。

## 历史聊天

- 顶部「历史聊天」页签或 `⌘⇧H` 打开：按项目分组浏览本机全部 Claude Code / Codex 会话记录，
  支持搜索、卡片详情、右键重命名/删除。
- **继续聊天**：详情页点「继续聊天」会新开终端并自动 `resume` 该会话；双击会话卡片也可以
  （已有同目录终端时直接聚焦过去）。
- 聊天记录会自动镜像到共享归档池，CC 清理 30 天前记录也不会丢（设置里可关）。

## AI 任务编排（任务中心 / 指挥台）

- **任务中心**：菜单「显示 → 任务中心」查看编排任务列表、审批待决项、查看任务详情与实时转写；
  任务详情就是可介入的实时终端，随时可以输入接管。
- **指挥台**：菜单「文件 → 新建指挥台」（`⌘⇧N`）开一个大脑终端，用自然语言下发任务、
  拆解执行、跨模型互审（详见指挥台内置说明）。
- 审批走结构化通道：worker 需要权限确认时会在任务中心弹审批项，不会盲按终端。

## 设置（右上角齿轮）

- **通用**：启动终端数量（下次启动生效）、双击聚焦、终端默认路径、Dock 角标通知
  （关闭/实时/定时，仅 macOS）。
- **外观**：主题下拉，5 套配色——dark / light / monokai / dracula / solarized-dark。
  选 light 界面转亮色，其余四套配暗色界面；切换立即全界面生效。
- **快捷键**：常用快捷键速查。
- **语言**：中文 / English，立即生效。
- **帮助**：新手引导重放、当前版本与更新内容（What's New）、检查更新。

## 登录（右上角小人图标）

- 支持 GitHub / Google / 邮箱密码三种登录方式；登录后头像出现在右上角，点头像可登出。
- 目前登录主要用于后续云端能力，日常本地使用不需要登录。

## 常见问题

- **终端没反应/等输入**：终端等待输入时右下会出浮卡提示，Dock 图标也会显示等待数字（可在设置改）。
- **误关了终端**：运行中会话关闭前都有确认框；已关闭的会话可去「历史聊天」里 resume。
- **主题切了颜色没变**：如果终端里的程序自己改过颜色（OSC 转义），主题只改默认色层，
  程序退出或重置后就会显示新主题色。
- **想重看新手引导**：设置 → 帮助 → 新手引导。

—— 更多问题直接在本终端问 Claude 即可。
